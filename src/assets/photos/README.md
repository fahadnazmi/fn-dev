# Photos

Drop your photographs here (`.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`).

They are picked up automatically by the gallery page, optimized by Astro
(resized, converted to modern formats, lazy-loaded) and sorted by filename.

Tip: prefix filenames with numbers (`01-sunrise.jpg`, `02-street.jpg`) to control order.
Use descriptive names, since the filename is used as the alt text.
